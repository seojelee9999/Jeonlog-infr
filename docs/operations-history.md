# 전록 운영 변경 기록

프로젝트 수행자가 제공한 운영 경험과 현재 저장소의 코드를 구분한 기록입니다. 프로젝트 기간은 **2025.11 ~ 2026.07**, 실제 서비스 운영은 **약 6개월**입니다. 각 변경의 정확한 날짜와 순서는 아직 확정하지 않았습니다.

## 현재 확인된 사실

| 항목 | 수행자 설명 | 저장소에서 확인되는 범위 |
| --- | --- | --- |
| 역할 | 8명 팀에서 개발환경 구축과 배포 담당 | Terraform 인프라·배포 권한·실행 스크립트 |
| 모니터링 | DAU·MAU 확인용 Grafana 대시보드 구성 | Grafana·Prometheus 설정 및 하드웨어 지표 화면; 이용 지표 쿼리는 미포함 |
| 네트워크 조정 | DB와 Grafana가 다른 리전에 있어 통신 비용 문제 발생; Grafana를 DB와 같은 리전·네트워크 대역으로 재배치 | 현재 코드는 같은 VPC의 public 모니터링 EC2와 private RDS를 구성 |
| 접근 구성 | DB와 Grafana를 비공개 접근 환경으로 두고 관리자 접속용 Bastion 사용 | 현재 코드에는 public IP가 있는 Grafana EC2와 그 SG의 DB 접근 허용이 남아 있음 |
| ALB | 운영 규모에 비해 비용이 커 운영 중 제거 | 현재 코드에는 ALB 모듈과 ASG Target Group 연결이 남아 있음 |
| 서비스 규모 | 종료 시 회원 130명, 유의미한 MAU 성과 없음 | 회원 통계 원본은 저장소에 없음 |

현재 Terraform이 최종 운영 상태와 일치한다고 주장하지 않습니다. 운영 이력을 맞추기 위해 검증되지 않은 리소스 변경을 임의로 코드에 적용하지도 않았습니다.

## 추가 확인할 세부 사항

### 네트워크와 비용

- 변경 전후 AWS 리전 이름과 VPC·AZ·서브넷의 상세 관계
- 통신 비용의 실제 청구 항목과 월별 전후 금액
- DB와 Grafana의 최종 배치 및 Grafana 데이터소스 연결 방식

수행자가 **서로 다른 리전이었다는 점과 Bastion이 관리자 접속용이었다는 점을 확인**했습니다. 리전 간 통신 비용에 대응한 배치 변경으로 설명하되, 구체적인 청구 항목과 절감액은 비용 자료 없이 단정하지 않습니다. Grafana의 DB 조회가 Bastion SSH 터널을 거쳤다고 작성하지 않습니다.

### ALB 제거 이후

수행자가 현재 세부 사항을 기억하지 못하는 부분입니다. 제출 문안에는 확인된 ALB 제거 사실만 반영하고, 아래 내용을 임의로 채우지 않습니다.

- 외부 요청을 받은 구성: EC2 직접 접속, Nginx 등 실제 사용 방식
- DNS·TLS 종료 방식과 배포 과정의 변경
- 상태 검사·장애 대응 및 단일 장애점에 대한 판단
- ALB 제거 전후 비용과 실제 절감액

### 이용 지표

- DAU·MAU의 활성 사용자 정의와 집계 기간·시간대
- 데이터 원천, 중복 사용자 집계 기준, 조회 방식
- Grafana 패널 또는 비밀값을 제거한 쿼리
- 종료 시 회원 130명이라는 수치의 확인 자료

## 성과 표현 기준

- 회원 130명을 MAU 130명 또는 동시 사용자 130명으로 바꾸지 않습니다.
- 측정 근거 없이 비용 절감률·가용성·배포 시간 개선 수치를 넣지 않습니다.
- 기존 하드웨어 대시보드 화면을 DAU·MAU 대시보드의 증거로 사용하지 않습니다.
- ALB 포함 Terraform은 보존된 구성, ALB 제거는 운영 중 변경 경험으로 구분합니다.
- 2026년 10월 포트폴리오 정리 중 추가한 CI와 포트 수정은 7월까지의 서비스 운영 성과에 포함하지 않습니다.
